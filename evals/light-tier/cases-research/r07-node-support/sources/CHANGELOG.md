# Changelog

## 3.4.0 — 2026-07-22
- Breaking: Node.js 18 is no longer supported (it reached end of life).
  The minimum is now Node.js 20.
- Added support for Node.js 24.
- `marlin deploy --watch` reloads on config changes.

## 3.3.1 — 2026-04-02
- Fix: `marlin init` on Windows paths with spaces.

## 3.2.0 — 2025-12-10
- Added Node.js 22 support.
