# Heron Auth — Configuration

Last updated: 2026-06-30

| Key | Default | Meaning |
|---|---|---|
| `session_timeout` | 30 minutes | Absolute lifetime of a session after sign-in |
| `idle_timeout` | disabled | Ends a session after this long without activity |
| `remember_me_days` | 14 | Lifetime of the "remember me" cookie |
