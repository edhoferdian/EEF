# PRD — Booking Lapangan Futsal

## Masalah
Pemilik lapangan mencatat booking lewat WhatsApp dan buku tulis; sering terjadi
jadwal bentrok.

## Fitur
1. Pelanggan melihat slot kosong per lapangan per jam.
2. Pelanggan booking slot dan membayar DP 50% lewat transfer.
3. Admin mengonfirmasi pembayaran dan bisa membatalkan booking.
4. Pengingat WhatsApp H-1.

## Di luar cakupan
Membership, turnamen.
